# ATM Application Coding Exercise

## Overview

Design and implement a web-based ATM application that lets a user manage two bank accounts. The goal is to showcase your software design and architecture within a focused scope.

## Requirements

1. A web-based ATM interface supporting: deposit funds, withdraw funds, and transfer between the two accounts
2. Track account balances and transaction history
3. Single-user (no authentication required)

## Technical guidelines

1. Backend: .NET/C#
2. Frontend: any technology you’re comfortable with. UX/design isn’t a primary scoring criterion, but good design is still good design — no need to over-invest (this isn’t a design role), just don’t disregard it entirely.
3. Database: in-memory or persistent — your call
4. AI: perfectly acceptable, but you must understand and be able to discuss the code you submit, the tradeoffs involved, and your overall approach and strategy

## Evaluation criteria

Code organization & architecture, separation of concerns, error handling, code quality/readability, and technical choices & tradeoffs.

## Time limit

Please spend no more than 2–4 hours; part of the exercise is deciding what to prioritize.

## Submission

A GitHub repo with setup instructions in the README, back to us by Tuesday, October 27 (sooner is welcome).
